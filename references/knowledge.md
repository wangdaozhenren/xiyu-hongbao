# 洗浴按摩红包助手 · 平台规则与叠加指南

> 本指南仅面向**正规合规**的洗浴、足疗、按摩、汗蒸、采耳等健康休闲场所。涉及灰色、违规场所的"红包""上门"一律不推荐、不引导。

## 一、各平台红包规则

### 美团（到店综合·洗浴按摩）
- **领取条件**：美团账号均可领；洗浴按摩类活动按城市开放，新用户有专享大额券
- **使用门槛**：多为满减券（如50元代100元）、一口价套餐券（如足疗60分钟特惠价）或折扣券（如5折体验）
- **有效期**：领取后一般7~30天有效，以券面为准；周末/节假日是否可用需看券面说明
- **是否可叠加**：到店券通常不可与门店其他优惠叠加；新客券限首次到店核销

### 大众点评（本地生活·洗浴）
- **领取条件**：点评账号可领，签到/点评评价可攒积分换券
- **使用门槛**：以团购套餐券为主，含门票+搓背/足疗等组合
- **有效期**：同美团，套餐券多为"随时退、过期退"
- **是否可叠加**：点评券同样一般不与门店会员卡叠加

### 抖音本地生活（洗浴直播团购）
- **领取条件**：直播间或团购页领取，部分需关注主播
- **使用门槛**：低价引流套餐（如9.9元门票、39元足疗体验），常限工作日闲时
- **有效期**：短则7天、长则30天，引流券有效期偏短，买前看清楚
- **是否可叠加**：抖音团购券与门店其他活动一般互斥

## 二、红包叠加逻辑

- **叠加顺序**：平台红包/团购券 → 门店套餐 → 门店会员卡折扣（通常不可叠加，以券面为准）
- **新客券最划算**：首次到店的新客券力度最大，建议留给心仪门店或心仪项目
- **拼团更省**：部分项目支持2~3人拼团，拼团价比单人券低（示例，以平台实时为准）
- **闲时券**：工作日下午（13:00-18:00）客人少，平台常放"闲时特惠"券，比周末晚场便宜

## 三、品类专属知识要点

### 3.1 正规场所鉴别（红线）
- 优先选美团/大众点评"品牌连锁""评分4.5以上""证照齐全"的门店
- 看到"上门服务""特殊服务""私影SPA"等暗示性广告词，直接跳过，不领、不推
- 团购套餐描述若刻意模糊服务内容、价格明显低于市场价一半以上，警惕灰色场所
- 本技能只引导正规健康休闲场所的优惠，**不诱导、不暗示任何违规消费**

### 3.2 套餐时长与项目明细
- 足疗/按摩券务必看**净时长**：60分钟套餐是指纯服务60分钟，还是含冲脚/更衣/茶歇
- 区分"含/不含搓背"：很多洗浴门票不含搓背、修脚、采耳，到店另付，买前看清套餐明细
- "加钟"另计费：按分钟或半小时加价，到店前问清加钟单价
- 汗蒸/洗浴类注意：毛巾、浴服、储物柜是否免费，部分店需付费购买

### 3.3 过夜费与闲时/周末价差
- 洗浴中心过夜需收**过夜费**（如凌晨2点后加收，示例以门店为准），券面通常不含
- 工作日下午闲时券力度最大，周五晚、周六全天、节假日普遍加价或不可用
- 周末/节假日预约紧张，建议提前1~3天电话或App预约技师

### 3.4 身体不适不宜按摩（健康提示）
- 饭后1小时内、饮酒后、发烧/急性炎症期、皮肤破损/传染性皮肤病期间**不宜按摩**
- 孕妇、骨质疏松、严重心脑血管疾病患者，按摩前应咨询医生，不盲目追求"力度大才解乏"
- 技师水平参差，可要求指定技师或中途更换；力度不适随时沟通，不必硬扛

## 四、新客与老客区别

- **新客专享**：到店新用户大额券（首单立减、5折体验券），限首次到店核销
- **老客可领**：每日签到红包、品类满减券、周末/闲时特惠券、评价返券
- **新老客通用**：平台通用到店红包、拼团券，无新老客限制
- 新客券只能用一次，建议留给最想体验的项目，别随便用在低价试水店

## 五、避坑指南

1. **虚假红包链接**：只通过美团/大众点评/抖音官方App领券，不点短信/微信里"低价洗浴"外链
2. **低价引流到店加价**：9.9元门票到店被加收浴服费、茶水费、搓背费，买券前看"费用包含/不包含"
3. **付费"特服"骗局**：任何要求微信私聊转账、加"技师"微信选服务的，均为违规/诈骗，立即退出
4. **券面陷阱**：引流券常限"周日至周四""不可与其他优惠同享""周末需补差价"，下单前逐条核对
5. **退款规则**：未使用随时退、过期自动退；已核销不支持退款，核销前确认门店与项目
